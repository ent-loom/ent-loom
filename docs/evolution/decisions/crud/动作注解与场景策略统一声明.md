# 动作与场景策略统一声明

动作声明统一在 `ent/entities/<资源码>.yml` 的 `crud.actions`，每个动作给出中文 name 与 entries，各入口独立声明 capability 和可选 portals。空 actions 关闭动作，省略不额外限制程序化场景策略。动作码与入口规范化，重复注册或超出实体边界拒绝。

文件编译为既有 ScenePolicy 与 ScenePolicyRegistry，Java ScenePolicy Bean 可在实体动作边界内补充入口，重复 key 拒绝。入口匹配不回退 base，不同入口权限不混用。

`@EntCrudCommandAction` 保留为 Handler 路由与泛型合同；Handler 超出实体动作白名单启动失败。权限白名单、业务授权、输入合同与事务仍由既有执行链落实。

完整语法见[配置参考](../../../guides/配置参考.md#实体-yaml)。

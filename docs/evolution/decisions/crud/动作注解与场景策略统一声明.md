# 动作与场景策略统一声明

业务动作在 Handler 的 `@EntCrudCommandAction` 中声明实体、动作、入口、能力及可选 portal，实体的 `@EntCrudEntity` 声明动作边界。动作码与入口规范化，重复注册或超出实体边界拒绝。

注解编译为既有 ScenePolicy 与 ScenePolicyRegistry，Java ScenePolicy Bean 可在实体动作边界内补充入口，重复 key 拒绝。入口匹配不回退 base，不同入口权限不混用。

`@EntCrudCommandAction` 同时声明 Handler 路由与泛型合同；Handler 超出实体动作白名单启动失败。权限白名单、业务授权、输入合同与事务仍由既有执行链落实。

完整语法见[配置参考](../../../guides/配置参考.md#实体注解)。

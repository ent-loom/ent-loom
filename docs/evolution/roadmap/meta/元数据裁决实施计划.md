## 切片约束

每个切片只允许一个主要运行时效果，并遵守：

1. 公共抽象必须是全局不变量，或已有两个真实模块共同使用。
2. 不因未来 DDL、DOC、UI 接入创建占位 SPI 或空泛型层级。
3. Convention 只产生 Contribution，不直接修改冻结模型。
4. 同一切片同时修改裁决算法、多个 Starter 和多个消费者时必须拆分。
5. 新扩展点必须有当前调用者、测试和可观察收益。

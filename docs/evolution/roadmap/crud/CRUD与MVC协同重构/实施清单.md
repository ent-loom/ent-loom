## 0. 盘点与准备

- [ ] 盘点旧 CRUD、授权、配置、Scene、DAO、Adapter、示例和文档的实际消费者，明确重做、复用或删除。
- [ ] 冻结首期资源、操作、HTTP、授权结果、字段用途和错误合同；为跨模块契约编写针对性测试。
- [x] 以 qyw 一个真实资源推演入口、学校与班级 / 学生集合范围的表达及交集，记录无法表达时的拒绝路径；不扩大首期 SQL 能力。见[实施记录](实施记录.md#qyw-资源合同推演)。
- [ ] 制定各能力关闭与切换顺序，确保每个完成阶段可构建、可测试，不产生平行入口或无授权回退。

## 1. 按次授权

- [x] 移除实体 YAML 读取，实体、字段、索引和 Handler 差异迁移到注解；示例的共享身份和策略迁移到 Java 配置，应用 YAML 保留运行部署配置。
- [x] 实现可信准入与按次授权：校验入口和范围选择，绑定访问者、已校验上下文、资源、操作及可选目标；缺失或不匹配时默认拒绝。
- [x] 框架执行器结合当前调用上下文和实际目标校验结果；验证跨请求、访问者、入口、资源、操作和目标误用时拒绝。
- [x] 实现范围 `ALL` / `NONE` / 受限条件、字段用途及静态上限；验证范围交集和字段收窄。
- [ ] 收敛声明来源与启动期校验，明确实体 / 操作开放边界；删除对应旧授权与配置路径。

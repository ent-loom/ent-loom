# 策略声明与缺省约定

全局 `ent.loom.crud.access` 声明共享 identities、policies、relations；实体文件 `ent/entities/<资源码>.yml` 的 `crud.policy` 唯一选择策略。字段授权、关系差异、归属、操作映射、输入契约与动作集中到同一文件。Java 保留类型、基础描述、关系结构和 Handler。

- 操作按动作覆盖：省略动作或空 operations 沿用策略标准缺省；非空列表整体替换该动作，空列表只保留业务动作；null 拒绝。
- 批量操作显式开放，每个目标独立授权；映射不授予权限，也不改变事务。
- 字段采用 INCLUDE/EXCLUDE/ALL/NONE，默认 EXCLUDE；INCLUDE 必须非空，ALL/NONE 不带字段，未知字段和重复用途拒绝。
- ownership 省略按全局关系与已有标量字段推导，显式列表整体替换，空列表关闭推导；底层范围约束仍保留。
- HTTP 实体必须有文件并显式选择 policy 或 access: JAVA，缺失拒绝启动；http-exposed: false 关闭通用 HTTP。
- Java 策略模板保留，操作声明、字段能力与复杂授权由项目程序化提供；文件与程序重复选择实体策略拒绝。

客户主数据通过 `access: JAVA` 显式保留已有治理链；受授权执行器尚无通用 CREATE，不为迁移增加执行能力。

完整语法见[配置参考](../../../../guides/配置参考.md#实体-yaml)，实现方向见[实体声明集中化方向](../../core/实体声明集中化方向.md)。

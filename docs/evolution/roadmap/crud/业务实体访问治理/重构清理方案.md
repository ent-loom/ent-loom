# 业务实体访问治理重构清理方案

> 状态：Current / Remaining
> 最近整理：2026-10-07
> 本轮已完成执行边界清理和提交历史收敛；本文保留剩余迁移项和后续边界。

## 1. 清理目标

把业务实体访问收敛到一条清晰主线：

```text
业务声明 → 编译冻结 → 按次授权 → 内置执行器/领域编排 → 受约束存储 → 结果与审计
```

普通请求走框架内置能力；手写代码只保留不能由标准实体操作表达的领域语义。清理依据是职责、真实消费者和安全合同，不是类名、行数或提交数量。

## 2. 关键决策

### 2.1 内置优先

以下请求优先使用现有 Query/Command/Stats/Import/Export Gateway、授权 DAO 和标准 JDBC：

- 单实体列表、分页、详情、筛选和排序；
- 单实体新增、修改、删除、版本和字段能力；
- 标准批量读取和批量更新；
- 标准统计、导入导出、任务状态和文件下载。

手写 Service/Handler 只负责跨实体事务、状态转换、外部副作用、复杂关系或特殊结果。它必须复用统一授权结果，不得另建权限链、直接调用无作用域 DAO 或拼接不受治理 SQL。

### 2.2 资源三态

| 状态 | 判定 | 行为 |
| --- | --- | --- |
| `GOVERNED` | 有冻结策略或显式受治理入口 | 缺上下文、授权、目标适用性或执行能力时执行前拒绝 |
| `LEGACY_ALLOWED` | R0 登记的存量消费者，尚未迁移 | 只允许原操作，不接收新增调用；进入治理作用域后按 `GOVERNED` 处理 |
| `UNKNOWN` | 没有策略、入口或存量登记 | 默认拒绝，不能按类名、路径或旧 DAO 推断可执行 |

冲突声明、未知动作/字段/关系属于编译错误；运行期缺能力、缺上下文和能力声明不完整属于拒绝。任何失败都不能回退到无范围旧路径。

### 2.3 不兼容清理

项目未上线，可以修改 API 并同步迁移仓库内消费者。不保留空转兼容外壳；仍有职责的逻辑先迁入唯一实现，再删除旧包装器。历史文档保留为证据，但不作为当前合同。

## 3. 保留、迁移和删除边界

| 对象 | 决策 |
| --- | --- |
| 强类型身份、可信上下文、认证准入 | 保留，属于安全基础 |
| `EntityPolicyTemplate/Binding/Registry` | 收敛为唯一静态模型和编译入口 |
| `BusinessAuthorizationService`、范围和字段结果 | 保留，作为统一授权内核 |
| 关系事实 SPI | 保留基础合同，按真实消费者扩展 |
| `LegacyCrudAuthorizationGuard` | 已删除；资源识别、能力检查和执行前拒绝已归并到 `ExecutionPipeline` |
| `ExecutionPipeline` | 保留通用编排，并直接承接业务授权适配与不支持执行形状的拒绝 |
| Query/Command/Stats/Import/Export Gateway | 保留内置能力，统一消费授权结果 |
| 标准形状的自定义 Handler/Service | 迁移到内置 Gateway/DAO 后删除 |
| 复杂领域动作 Handler | 保留，但只做领域编排 |
| 自定义 SQL | 优先改为内置执行；无法表达时显式适配，复杂关联继续拒绝 |
| 无消费者的扩展层和包装器 | 完成引用审计后删除或移出本轮 |

## 4. 实施顺序

| 阶段 | 工作 | 退出条件 |
| --- | --- | --- |
| R0 | 建立资源/操作/消费者矩阵；标记内置、手写、暂不支持 | 每个消费者都有去留、替代位置和证据 |
| R1 | 冻结资源三态、声明冲突、缺省和拒绝原因 | 当前、目标、历史文档分层一致 |
| R2 | 标准请求迁入内置 Gateway/DAO；复杂动作保留薄 Handler | 无重复授权、过滤、分页、SQL 和审计代码 |
| R3 | 将资源识别和执行能力检查放回统一入口 | `UNKNOWN` 和不支持能力不会进入副作用 |
| R4 | 已删除 `LegacyCrudAuthorizationGuard` 和空转测试 | 所有消费者通过唯一执行边界，安全回归通过 |
| R5 | 更新当前流程、清单、架构和指南 | 使用者能判断当前支持、扩展要求和剩余项 |

## 5. 验收

- 标准分页、详情、单目标写入、批量读取和批量更新仍保持范围、字段、版本、事务和审计行为。
- 普通请求不再新增业务 Handler；必要 Handler 只编排内置能力。
- 缺可信上下文、授权结果、关系事实或存储能力时，在 SQL 或业务副作用前拒绝。
- 直接 DAO、自定义 SQL、统计、导入导出都不能绕过统一操作授权。
- 文档中 `Current`、`Target`、`Remaining` 和历史证据互不混写。

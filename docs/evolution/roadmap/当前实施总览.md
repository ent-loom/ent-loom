## 最近完成的业务闭环

mini-commerce 的订单列表、分页、详情统一通过内置 CRUD，客户与商家共用 `Order`、`order/view` 和全局 `order-read` 策略，身份范围与请求筛选取交集，数据与 count SQL 同条件。一级关联按父资源 EXPAND 字段投影授权并批量读取，商家不返回客户邮箱；两个查询 Controller、DTO、Service 和局部授权组装配置已删除。

下单仍经过显式业务动作的入口、能力和主体场景授权，保留拆单、成交快照与失败回滚；未迁入可信客户聚合创建授权。下一阶段边界见[标准查询统一入口实施计划](crud/标准查询统一入口实施计划.md)。

本轮 JDK 21 完整 ent-loom Reactor 1104 项测试无失败（4 项专用 MySQL 默认跳过），示例 82 项无失败（3 项专用 MySQL 表结构默认跳过）。当前使用方式见[双端分页入口与范围](../../guides/crud/双端分页入口与范围.md)和[受授权关联读取](../../guides/crud/受授权关联读取.md)。

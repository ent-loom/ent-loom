## 最近完成的业务闭环

G4.32 双端订单分页已收敛为 `Order → OrderItem` 两层模型：资源码 `order`、表 `order`，客户按 `customerId`、商家按 `merchantId` 读取，count 与数据条件一致。一次跨商家下单自动创建多张独立订单，事务内保存成交快照；下单与详情通过业务入口，通用订单 HTTP 关闭。

示例 H2 全回归 55 项（含双端真实 HTTP/H2 25 项）、脚本单测 8 项通过，Java 打包成功；JDK 21.0.12.1 真实 MySQL 整轮验收 exit 0，应用正常关闭，容器、数据卷与网络已清理。具体使用与最终日志证据见[双端分页入口与范围](../../guides/crud/双端分页入口与范围.md)及[实施记录 G4.32](crud/业务实体访问治理/实施记录.md#56-g432-同一商家子订单的双端分页入口与范围)。

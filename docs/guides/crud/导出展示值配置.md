# 导出展示值配置

> 状态：Current
> 最近核验：2026-08-21

本文说明业务如何配置默认导出列和展示值。执行主链与能力边界见
[Export 当前实现](../../architecture/components/crud/导出.md)。

## 字段配置

在需要覆盖默认行为的字段上使用 `@EntCrudExportField`：

```java
@EntCrudExportField(label = "学生", displayField = "studentName")
private Long studentId;

@EntCrudExportField(label = "状态", dictionaryCode = "student_status")
private StudentStatus status;

@EntCrudExportField(label = "发生时间", format = "yyyy-MM-dd HH:mm")
private LocalDateTime occurredAt;

@EntCrudExportField(exportable = false)
private String internalRemark;
```

| 属性 | 用途 |
|---|---|
| `exportable` | 是否允许导出 |
| `defaultVisible` | 未显式指定 `fields` 时是否默认展示 |
| `label` | 导出表头 |
| `format` | 时间、数字、布尔等格式提示 |
| `dictionaryCode` | 交给 `ExportDictionaryResolver` 转换展示文本 |
| `displayField` | 外键对应的同表展示字段 |

`displayField` 当前只支持同表字段，不支持 `student.name` 这类关系路径。

## 字段选择

未传 `fields` 时，框架按 Runtime Model 的稳定顺序生成默认列，并排除：

- 主键、逻辑删除字段和关系对象字段。
- 租户、组织、操作者、版本等内置内部字段。
- `exportable=false` 或 `defaultVisible=false` 的字段。
- 关系外键和存在合法 `xxxName` 展示字段的 `xxxId`。

显式传入 `fields` 仍必须通过字段存在性、读取白名单和导出元数据校验。主键、外键 ID、
逻辑删除、关系对象及内部字段不会因为显式指定而放行；特殊场景应使用自定义 Export Handler。

## 展示值

默认渲染规则：

| 类型 | 展示 |
|---|---|
| `null` | 空字符串 |
| Boolean | `是` / `否`，可通过 `format` 覆盖 |
| Enum | `ExportDisplayEnum`，再尝试 `getDesc/getDescription/getLabel/@JsonValue`，最后使用 `name()` |
| `LocalDate` | `yyyy-MM-dd` |
| 日期时间 | `yyyy-MM-dd HH:mm:ss` |
| `LocalTime` | `HH:mm:ss` |
| Number | 保留数值类型，配置格式时再格式化 |

字典解析器存在且字段设置 `dictionaryCode` 时，字典展示优先于默认枚举和基础类型渲染。

## 时区

通过请求的 `renderOptions.timezone` 指定导出展示时区：

```json
{
  "format": "excel-xlsx",
  "fields": ["orderNo", "createdAt"],
  "renderOptions": {
    "timezone": "Asia/Shanghai"
  }
}
```

非法时区直接失败。`Instant`、`Date` 等绝对时间按该时区转换；`LocalDateTime` 不做时区换算。

## 扩展边界

- 自定义字典文本：实现 `ExportDictionaryResolver`。
- 特殊字段组合、关系路径或复杂报表：实现业务 Export Handler。
- Excel writer 只消费 `ExportTable`，不承载字段权限、业务枚举或关系策略。
- Preview 与 Submit 共用列解析和展示值渲染，业务不应分别维护两套规则。

# 快速开始

> 正式交付：固定使用 `ent-loom 1.0.1`。2026-09-09，GitHub Actions 运行 `34333670911` 使用全新 Maven 本地仓库，仅下载公开构件，完成本页单表示例的真实启动、HTTP 请求和 MySQL SQL 核对。

本页带你运行第一个真实消费者项目：`customer-profile-spring-boot`。它的 POM 固定消费 Maven Central 的 `ent-loom 1.0.1`，在 MySQL 8 上通过真实 HTTP 完成 `CustomerProfile` 的创建和详情查询。

完整可运行工程、配置说明、IDEA 启动方式、Windows 命令和故障日志位置见 GitHub 上的 [`customer-profile-spring-boot README`](https://github.com/ent-loom/ent-loom/tree/main/examples/customer-profile-spring-boot)。

## 前置条件

- JDK 21+
- Maven 3.9+
- MySQL 8.0+；干净验收另外需要 Docker Compose v2.20+
- Python 3.9+；仅用于非交互验收脚本

示例是独立 Maven 消费者，不继承 ent-loom 内部父 POM，也不依赖 `ent-loom-tests` 或内部实现类。公开构件坐标见 [Maven Central](https://central.sonatype.com/search?q=io.github.ent-loom)。

`ent-loom 1.0.1` 已修复 CRUD Starter 的自动配置顺序问题，并通过公开版本真实启动验收。

## 获取工程

```bash
git clone https://github.com/ent-loom/ent-loom.git
cd ent-loom/examples/customer-profile-spring-boot
```

POM 固定使用以下公开构件版本：

```xml
<properties>
    <java.version>21</java.version>
    <ent-loom.version>1.0.1</ent-loom.version>
</properties>
```

## 启动 MySQL 和应用

日常开发可连接本机 MySQL 8.0+。在示例目录创建环境文件并准备数据库：

```bash
cp .env.example .env
mysql -u root -p -e "create database if not exists customer_profile; create user if not exists 'customer_profile'@'localhost' identified by 'customer_profile_dev'; alter user 'customer_profile'@'localhost' identified by 'customer_profile_dev'; grant all privileges on customer_profile.* to 'customer_profile'@'localhost'; flush privileges;"
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

应用启动后，健康检查为 [http://localhost:8080/actuator/health](http://localhost:8080/actuator/health)。`dev` profile 会执行 `schema.sql`，示例显式配置实体类名、实体白名单、开发态主体、权限规则和 CRUD Controller；这些配置只适合本地演示。

## 创建并查询实体

创建请求：

```bash
curl -X POST http://localhost:8080/api/ent-crud/customer_profile/create \
  -H 'Content-Type: application/json' \
  -d '{"options":{"requestId":"customer-profile-create-1"},"payload":{"id":1000000000001,"displayName":"Ada Lovelace","email":"ada@example.com"}}'
```

使用创建响应中的 `data.id` 查询详情：

```bash
curl -X POST http://localhost:8080/api/ent-crud/customer_profile/detail \
  -H 'Content-Type: application/json' \
  -d '{"options":{"requestId":"customer-profile-detail-1","filterMap":{"id":{"op":"EQ","value":1000000000001}}}}'
```

响应中的 `display_name` 和 `email` 应与 MySQL 中的记录一致。HTTP 请求文件见 [`requests/customer-profile.http`](https://github.com/ent-loom/ent-loom/blob/main/examples/customer-profile-spring-boot/requests/customer-profile.http)。

## 干净环境验收

验收脚本会使用独立 Compose 项目、数据卷和随机端口，不读取本机 `.env`，并在成功或失败后清理本次资源：

```bash
python3 scripts/verify.py
```

脚本覆盖应用构建、MySQL 健康检查、真实 CREATE、DETAIL、SQL 字段核对和日志保留。失败日志位于 `target/verification-logs/<项目名>/`。

商城业务协作示例见 [`mini-commerce-spring-boot`](https://github.com/ent-loom/ent-loom/tree/main/examples/mini-commerce-spring-boot)，演示通用主数据、事务下单 Handler、价格快照和订单详情；已通过公开构件真实启动、事务回滚和历史价格快照验收。

## 当前工作区构件验收

修改框架源码时，从 ent-loom 根目录安装到隔离 Maven 仓库，再运行示例脚本；此路径不作为公开版本消费验收的证据：

```bash
repo=$(mktemp -d)
./mvnw -B "-Dmaven.repo.local=$repo" -DskipTests -Dmaven.javadoc.skip=true install
cd examples/customer-profile-spring-boot
python3 scripts/verify.py --maven-repository "$repo"
```

# 配置参考

> 状态：Current
> 最近核验：2026-09-23

本文是 Spring Boot 配置的统一入口。`docs-site` 直接展示 `ent-loom/docs`，这里是唯一权威正文；配置前缀、类型和默认值以各模块的 `@ConfigurationProperties` 为准。

## 怎么读

示例工程只展示业务闭环需要的 P1 配置，并允许少量 P2 配置。完整配置项仍在本文按模块列出，不要求业务项目一次性复制。

| 标记 | 含义 | 使用建议 |
|---|---|---|
| P1 | 常见能力的推荐配置，或接入该能力时需要明确的配置 | 按实际启用的能力显式填写 |
| P2 | 默认值通常可用，但特定环境可能需要调整 | 只有改变默认行为时填写 |
| P3 | 专项、兼容或高级配置 | 先确认前置条件，再单独配置 |
| 安全边界 | 与暴露范围、主体或权限有关 | 即使不是 P1，也必须显式确认 |

级别表示“是否推荐填写”，不等于“是否有默认值”。`enabled`、实体来源和 HTTP 暴露范围要结合生效条件理解；安全配置不能因为存在默认值而省略审查。

## 配置归属

当前 Spring Boot 配置项由以下绑定类提供。没有 `@ConfigurationProperties` 的 Core 运行时对象不属于公开 YAML 配置。

| 模块 | 配置前缀 | 绑定类 | 说明 |
|---|---|---|---|
| Meta | `ent.loom.meta` | `EntLoomMetaProperties` | 实体来源、Meta 到 CRUD / DOC 的投影和诊断 |
| Meta 文档契约 | `ent.loom.doc.contract` | `EntityDocumentationContractProperties` | 文档契约暴露和 HTTP 入口 |
| CRUD | `ent.loom.crud` | `CrudProperties` | Controller、Query、Command、治理、幂等和导入导出 |
| CRUD 示例 | `ent.loom.crud.example` | `CrudExampleProperties` | 仅供本地示例使用的主体和数据范围 |
| DDL | `ent.loom.ddl` | `EntDdlProperties` | DDL 开关、实体来源和执行级别 |

DOC Core 当前没有独立的 Spring Boot 配置类；文档契约适配属于 Meta starter，因此使用 `ent.loom.doc.contract`。

## Meta

### `ent.loom.meta`

| 配置项 | 类型 | 默认值 | 级别 | 说明 |
|---|---|---:|---|---|
| `enabled` | boolean | `true` | P2 | 总开关；关闭后不装配 Meta 适配器 |
| `base-packages` | `list<string>` | `[]` | P1 / 实体来源 | 递归扫描包及子包中的 `@EntEntity`、`@EntCrudEntity`、`@EntDocEntity` 具体实体类 |
| `entity-class-names` | `list<string>` | `[]` | P1 / 实体来源 | 未自行提供 `ResourceCatalogAdapter` 时，声明参与投影的实体全限定类名 |
| `crud.enabled` | boolean | `true` | P1 | 是否启用 Meta 到 CRUD 的适配器 |
| `doc.enabled` | boolean | `true` | P1 | 是否启用 Meta 到 DOC 的适配器 |
| `diagnostics.fail-fast` | boolean | `true` | P2 | 元数据诊断发现错误时是否快速失败 |

`base-packages` 支持 Spring 包路径匹配：`*` 匹配一层包，`**` 匹配零层或多层包，例如 `com.example.minicommerce.*.entity`；匹配到的包仍递归扫描子包。

通过 `base-packages` 扫描包，或通过 `entity-class-names` 精确指定实体；两者同时配置时按全限定类名合并去重、排序。均为空时不自动扫描，也不注册 Meta 适配器，应用可自行提供 `ResourceCatalogAdapter`。包扫描只发现实体，不会将实体注册为 Spring Bean；HTTP 暴露仍需单独配置。

### `ent.loom.doc.contract`

| 配置项 | 类型 | 默认值 | 级别 | 说明 |
|---|---|---:|---|---|
| `enabled` | boolean | `false` | P1 / 启用文档 HTTP 时必填 | 启用文档契约服务 |
| `exposure.enabled` | boolean | `false` | 安全边界 | 打开文档暴露能力 |
| `exposure.subject-ids` | `set<string>` | `[]` | 安全边界 | 允许访问文档契约的主体；空集合不提供授权主体 |
| `exposure.fields` | `map<string, set<string>>` | `{}` | P1 / 安全边界 | 按资源编码限制字段；未列出的字段不应默认对外暴露 |
| `http.enabled` | boolean | `false` | P1 | 启用 HTTP 文档契约入口 |

`enabled`、`exposure.enabled` 和 `http.enabled` 是三层独立开关。需要 HTTP 文档时应同时检查三者以及主体、字段白名单。

## CRUD

### `ent.loom.crud`

以下表覆盖 `CrudProperties` 当前所有公开嵌套字段。集合的空值语义逐项定义；例如`EXPLICIT` 模式下空 `controller.include-entities` 不暴露任何实体，不能统一理解为“不额外限制”。

#### 基础与输入契约

| 配置项 | 类型 | 默认值 | 级别 | 说明 |
|---|---|---:|---|---|
| `contracts.create.input-required-fields` | `map<string, list<string>>` | `{}` | P1 | 按资源声明创建请求必须提供的字段 |
| `contracts.update.forbidden-fields` | `map<string, list<string>>` | `{}` | P1 | 按资源声明更新请求禁止修改的字段 |
| `sql-log.mode` | enum `SAFE` / `FULL` | `SAFE` | P2 | SQL 日志是否包含参数明细；生产环境保持 `SAFE` |
| `sql-log.sample-rate` | double `[0,1]` | `0.1` | P2 | SQL 日志采样率 |
| `sql-log.output` | enum `TEMPLATE` / `EXEC` / `BOTH` | `TEMPLATE` | P2 | 输出模板 SQL、可执行 SQL 或两者 |
| `sql-log.pretty` | boolean | `false` | P2 | 是否格式化 SQL 日志 |

#### Controller 与 Query

| 配置项 | 类型 | 默认值 | 级别 | 说明 |
|---|---|---:|---|---|
| `controller.enabled` | boolean | `false` | P1 | 启用框架默认 HTTP Controller |
| `controller.base-path` | string | `/api/ent-crud` | P2 | 默认 CRUD HTTP 基础路径 |
| `controller.default-timezone` | string | `Asia/Shanghai` | P2 | time 参数默认时区 |
| `controller.default-time-field` | string | 空 | P2 | 默认时间字段；空值不自动补充 |
| `controller.default-read-result-mode` | enum `MAP` / `ENTITY` | `MAP` | P2 | 默认读结果模式 |
| `controller.default-null-field-mode` | enum `INCLUDE` / `OMIT` | `OMIT` | P2 | 默认是否保留空字段 |
| `controller.exposure-mode` | `enum` | `EXPLICIT` | P1 / 安全边界 | `EXPLICIT` 按包含清单暴露；`ALL_REGISTERED` 暴露所有已注册 CRUD 实体，不能同时配置非空包含清单 |
| `controller.include-entities` | `set<string>` | `[]` | P1 / 安全边界 | `EXPLICIT` 模式允许路由的实体；空集合不暴露任何实体。两种模式均服从实体 `@EntCrudEntity(httpExposed = false)`，不影响内部 CRUD 调用；操作授权仍由权限规则控制 |
| `controller.string-filter.default-like-enabled` | boolean | `false` | P2 | 字符串简写是否默认转 LIKE |
| `controller.string-filter.default-like-mode` | enum `CONTAINS` / `PREFIX` / `SUFFIX` / `RAW` | `CONTAINS` | P2 | 默认 LIKE 模式 |
| `controller.string-filter.default-like-exclude-fields` | `set<string>` | `path, fullPath, parentPath, url, uri` | P2 | 不自动套 LIKE 的字段 |
| `query.enabled` | boolean | `true` | P1 | 启用 Query 主链 |
| `query.default-sort.enabled` | boolean | `true` | P2 | 启用默认排序补全 |
| `query.default-sort.apply-to` | `set<enum>` | `PAGE, LIST` | P2 | 生效入口：`PAGE`、`LIST`、`DETAIL`、`FIND_ONE` |
| `query.default-sort.time-fields` | `list<string>` | `createTime, createdAt, createDate, createdTime, gmtCreate, insertTime` | P2 | 按顺序匹配的时间字段 |
| `query.default-sort.time-direction` | enum `ASC` / `DESC` | `DESC` | P2 | 时间字段排序方向 |
| `query.default-sort.append-id` | boolean | `true` | P2 | 是否追加主键排序保证分页稳定 |
| `query.default-sort.id-direction` | enum `ASC` / `DESC` | `DESC` | P2 | 主键排序方向 |
| `query.default-sort.fallback-to-id` | boolean | `true` | P2 | 没有时间字段时是否回退到主键 |

#### 幂等、治理与分页保护

| 配置项 | 类型 | 默认值 | 级别 | 说明 |
|---|---|---:|---|---|
| `idempotency.mode` | enum `OPTIONAL` / `REQUIRED` | `OPTIONAL` | P2 | 幂等键要求模式 |
| `idempotency.required-ops` | `set<CommandOperation>` | `[]` | P1 / 按业务需要 | 必须提供幂等键的操作集合 |
| `idempotency.required-scenes` | `set<string>` | `[]` | P1 / 按业务需要 | 必须提供幂等键的场景集合 |
| `idempotency.retention-hours` | long | `48` | P2 | 幂等记录保留小时数 |
| `idempotency.table-name` | string | `entloom_idempotency_record` | P2 | 幂等记录表名 |
| `idempotency.auto-initialize-schema` | boolean | `true` | P2 | 是否自动初始化幂等表 |
| `governance.permission-rules` | list | `[]` | 安全边界 | 按资源、动作、场景和主体声明 `ALLOW` / `DENY` 等决策 |
| `governance.read-visibility` | map | `{}` | 安全边界 / 按业务需要 | 实体资源码 → 可信业务入口 → 字段等值或 IN 条件；入口的 all 不追加限制，未声明入口拒绝读取 |
| `governance.audit.persist-to-jdbc` | boolean | `true` | P1 / 按审计要求 | 是否持久化治理审计 |
| `governance.audit.auto-initialize-schema` | boolean | `true` | P2 | 是否自动初始化审计表 |
| `governance.audit.table-name` | string | `entloom_crud_governance_audit` | P2 | 审计表名 |
| `dao.pagination.max-page-size` | int | `200` | P2 | 自定义 DAO 单页最大条数 |
| `dao.pagination.max-offset` | long | `1000000` | P2 | 自定义 DAO 最大分页偏移 |

权限规则至少应明确 `resource`、`action`、`scene`、`decision` 和主体范围。生产环境不要依赖示例主体或全量数据范围。

读取可见性不会授予权限。已纳管实体未匹配可信业务入口时拒绝读取；入口识别、配置示例与关联执行边界见[读取可见性](./读取可见性.md)。

## DDL

### `ent.loom.ddl`

| 配置项 | 类型 | 默认值 | 级别 | 说明 |
|---|---|---:|---|---|
| `enabled` | boolean | `false` | P1 | 启用 DDL starter |
| `schema` | string | 空 | P1 | 目标数据库 schema；空值使用数据源默认 schema |
| `create-database-if-missing` | boolean | `false` | P2 | 是否允许启动时创建数据库 |
| `mode` | enum `NONE` / `CREATE_TABLE` / `CREATE_TABLE_AND_METAS` / `CREATE_MODIFY_TABLE_AND_METAS` / `CREATE_MODIFY_DELETE_ALL` | `NONE` | P1 | DDL 执行级别；生产环境按迁移策略选择 |
| `base-packages` | `list<string>` | `[]` | P1 / 二选一 | 扫描实体包 |
| `entity-class-names` | `list<string>` | `[]` | P1 / 二选一 | 直接声明实体类名 |

`base-packages` 与 `entity-class-names` 是两种实体来源方式，实际启用 DDL 时至少确认一种来源和执行级别。涉及删除或修改的模式应在迁移窗口内使用。

## 示例与维护规则

最小业务示例见 [mini-commerce-spring-boot 的配置](../../examples/mini-commerce-spring-boot/src/main/resources/application-example.yml)；它只保留 P1、少量 P2 和必要的安全边界。全量字段参考以本文为准，不额外维护一个长期漂移的 full-demo YAML。

配置维护遵循以下顺序：

1. 在所属模块的 `@ConfigurationProperties` 中新增字段、默认值和中文 Javadoc。
2. 保留 `spring-boot-configuration-processor`，构建时生成 `META-INF/spring-configuration-metadata.json`，让 IDE 能提示配置。
3. 在本文补充路径、默认值、级别、生效条件和安全语义。
4. 更新最小示例只有在业务闭环确实需要该配置时才进行。

条件装配读取的开关也必须在本文出现；未被配置绑定类或条件装配读取的内部字段不作为公开配置。发现源码默认值与本文不一致时，以源码为准并立即修正文档。

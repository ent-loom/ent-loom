# 使用指南

本目录面向业务开发者，说明如何接入和使用当前能力。公共契约见[当前架构](../architecture/index.md)；源码修改后的验收流程见[本地开发与验收](本地开发与验收.md)。

## 推荐顺序

1. [快速开始](快速开始.md)：从零创建 Spring Boot 应用，用一个实体体验建表、数据读写和实体文档。
2. [Meta：实体建模](meta/index.md)：理解实体、字段、关系与通用业务约束。
3. [CRUD：数据操作](crud/index.md)：在实体模型上执行查询、命令和场景定制。
4. [示例工程](示例工程.md)：查看完整 Spring Boot 接入和业务扩展。

环境配置、源码验收和发布属于维护流程，统一放在侧栏“设计与维护 → 维护者指南”。

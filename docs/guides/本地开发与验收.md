# 本地开发与验收

> 状态：Current

本页面向修改 ent-loom 源码后的维护者。第一次使用框架请先看[快速开始](快速开始.md)，不要把本页的源码验收流程当作业务接入步骤。

## 公开版本验收

示例脚本会创建独立的 Compose 项目、数据卷和随机端口，不读取本机 `.env`，并在结束后清理资源：

```bash
cd examples/customer-profile-spring-boot
python3 scripts/verify.py
```

脚本覆盖应用构建、MySQL 健康检查、真实 CREATE、DETAIL、SQL 字段核对和日志保留。失败日志位于 `target/verification-logs/<项目名>/`。

## 当前源码验收

从 ent-loom 根目录安装到临时 Maven 仓库，再让示例只消费这份构件：

```bash
repo=$(mktemp -d)
./mvnw -B "-Dmaven.repo.local=$repo" -DskipTests -Dmaven.javadoc.skip=true install
cd examples/customer-profile-spring-boot
python3 scripts/verify.py --maven-repository "$repo"
```

这条路径验证当前工作区源码，不替代公开版本发布验收。完整的模块级测试命令和阶段证据见[路线图](../evolution/roadmap/index.md)。

## 版本基线

- 完整 Maven Reactor 使用 JDK 21+。
- 示例使用 `ent-loom 1.0.1` 和 MySQL 8+。
- Core / Java 8、Boot 2 与 Boot 4 仍是目标兼容路线，详见[Java 与 Spring 兼容性](../evolution/decisions/core/Java运行时与Spring兼容性.md)。

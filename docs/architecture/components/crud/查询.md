# 查询当前实现

> 状态：Current
> 最近核验：2026-08-21
> 范围：`ent-loom-crud`

Query 是 CRUD 的只读能力域，负责单表读取、受控关系展开、场景查询和默认 JDBC 查询。

## 当前能力

| 能力 | 当前实现 |
|---|---|
| Gateway | `QueryGateway` |
| Spec | `QuerySpec` |
| 操作 | `PAGE`、`LIST`、`FIND_ONE`、`DETAIL` |
| 路由 | `DefaultQueryRouter` + `SceneHandlerRegistry` |
| 默认引擎 | `JdbcQueryEngine` |
| 关系策略 | 默认 `ROOT_FIRST`，有限关系展开 |
| `EXISTS` 关联过滤 | 仅 Java 内部受控 API；本地库、根实体一跳、目标实体直接字段 |
| 治理 | `governQuery`，读取前完成主体、权限、数据范围和审计 |

## 已绑定业务策略的查询

`QueryGateway` 对已绑定新策略的资源直接调用 `AuthorizedQueryExecutor`，执行按次业务授权、范围 SQL、字段用途校验、白名单投影与审计，不进入旧查询路由。内置通用 HTTP 已为这类资源提供 REQUIRED 可信准入，普通根实体的四种读取无需业务 Controller；新授权查询不依赖旧主体解析器。

当前支持根实体 `CrudRecord` 与父资源 `EXPAND` 授权的本地一级关联字段投影；声明式策略缺省允许候选关联普通字段，本次仍需显式请求展开。关联范围仅限实际授权根记录的连接键，并保留逻辑删除。根实体分页、count 与批量补数分离。实体 / DTO 及一级关联 DTO 按结果字段完整授权；场景、多实体连接、关系筛选、嵌套及远程展开继续拒绝。上表其他默认引擎、场景和关系能力仍属于原有查询链，不能跨过新授权适配边界。详见[受授权关联读取](../../../guides/crud/受授权关联读取.md)。迁移与依赖见[标准查询统一入口实施计划](../../../evolution/roadmap/crud/标准查询统一入口实施计划.md)。

## 语义边界

- `detail` 表示必须存在，不存在抛稳定错误。
- `findOne` 表示允许不存在，但不允许结果不唯一。
- 默认 Query 不是通用 JOIN 生成器。
- HTTP 查询合同不接收 `EXISTS` 策略或关联过滤；需要该能力时由 `QuerySceneHandler` 在服务端构造 `QuerySpec`。
- 关联字段过滤、排序和复杂多跳规划不属于当前默认能力。

详细 Spec、routeKey 和 HTTP 合同见 [Query/Command 协议与路由明细](查询命令协议.md)。

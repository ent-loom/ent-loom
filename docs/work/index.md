# 实施工作区

本目录记录当前正在实施的路线、阶段清单、验收项和过程性边界。这里的内容用于推动变化，不是当前运行契约的权威来源。

## 使用规则

- 规范性结论维护在 `docs/architecture/`。
- 已确认的长期目标维护在 `docs/roadmap/`。
- 实施完成后，把最终结论提炼回 `docs/architecture/`。
- 已结束或被替代的过程文档移入 `docs/archive/`。
- 工作文档应标明状态、范围和对应的规范性来源。

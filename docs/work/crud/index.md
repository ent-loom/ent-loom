# CRUD 实施工作区

本目录记录 CRUD 尚未完全落地的边界方案、实施步骤和验收材料。当前 CRUD 契约和实现事实仍以 [CRUD 文档入口](../../architecture/components/crud/index.md) 为准。

## 当前材料

- [Scene Policy 治理边界](scene-policy-governance.md)：资源、入口、场景能力点与治理链的实施方案。

## 使用规则

- 方案被代码和测试验证后，提炼为 `architecture/components/crud/` 下的当前契约。
- 仍处于目标设计或分阶段实施的内容，不放入当前实现文档。
- 长期优先级进入 [CRUD 路线图](../../roadmap/crud/index.md)；已结束材料进入 `docs/archive/`。
